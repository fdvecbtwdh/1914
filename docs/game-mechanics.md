## 1. 单位类型总览

### 1.1 单位属性表

| 单位类型 | 视野范围 | 攻击范围 | 基本入场规则 | 移动规则 |
|----------|----------|----------|-------------|----------|
| **骑兵** | 周围四格 | 周围八格 | 可以部署在任意友方占领度满（100%）的地方 | 每友方回合，可选择移动或攻击共一次 |
| **步兵** | 周围四格 | 周围八格 | 可以部署在友方后方；若占领前线，可部署在友方阵地 | 每友方回合，可选择移动或攻击共一次 |
| **坦克** | 周围八格及向前额外一格 | 周围八格 | 可以部署在友方后方；若占领前线，可部署在友方阵地 | 每友方回合，可选择攻击一次，移动无限制 |
| **战斗机** | 前方横向 3×2 格子 | 单位所在列和相邻两列 | 可以部署在友方后方；若占领前线，可部署在友方阵地 | 每友方回合，可选择移动或攻击各一次 |
| **轰炸机** | 前方横向 3×2 格子 | 单位所在列和相邻两列 | 可以部署在友方后方；若占领前线，可部署在友方阵地 | 每友方回合，可选择移动或攻击各一次 |
| **火炮** | 前方横向 3×3 格子 | **全图** | 可以部署在友方后方 | 每友方回合，可选择移动或攻击各一次 |
| **工事** | 所在阵线 | 无 | 可以修筑在任意友方占领度为 100% 的阵线 | 无法移动 |

### 1.2 陆军与空军图层（2026-09-20 增补）

陆军（步兵/骑兵/坦克/火炮/工事）与空军（战斗机/轰炸机）属于**不同图层**：

1. 空军位于**空域图层**，陆军位于**地面图层**，两层使用相同的行列坐标系但互不占位
2. 陆军单位所在格**不阻止**空军进驻该格上空；反之亦然
3. 部署、移动的占位检查只在**本方图层**内进行
4. 攻击可以跨层（按各兵种攻击/反击规则），射程按行列几何判定
5. 空军不可越过规则：空域无阻挡概念，空军移动仍为一格八方向

### 1.3 备注

- **移动：** 一般地，移动时可向周围八个格子择一移动一格，消耗一次行动花费。
- **后退：** 陆军与空军单位可向己方后方（行号减小/增大方向）移动一格，称为**后退**。后退消耗本回合**全部行动**（移动 + 攻击均不可再进行），且不能退出棋盘边界。除后退外，任何单位不得向后方移动。
- **部署回合行动限制：** 单位部署的当回合**不能移动**（含后退）；**可以按攻击规则正常攻击**。拥有**突击**词条的单位部署当回合可以移动和攻击。
- **生产：** 一般地，所有单位均须先行使用经济 G 生产，在购买次回合方可消耗对应战争点 Z 部署。
- **消灭奖励：** 一般地，消灭敌方单位时，获得 25% 的该单位生产经济 G。
- **骑兵：** 作为兵种不自带"冲锋"；"冲锋"仅为个别卡牌的词条。部署规则为可部署在任意友方占领度满（100%）的地方。

## 2. 基础词条

### 2.1 词条总表

| 词条 | 效果 | 备注 |
|------|------|------|
| **守护** | 为相邻友方单位添加具有本单位指向的"被守护"词条 | |
| **被守护** | 本单位受到周围八格部队造成的伤害时，视为攻击指向本单位的"守护"单位 | |
| **响应** | 本单位生产后可以在同一回合部署 | |
| **突击** | 本单位进入战场后可以直接操作（部署当回合可移动和攻击，且部署当回合攻击免反击） | |
| **坚守** | 本单位交战时，实际受到伤害 = 原伤害 − "坚守"等级 | 坚守等级范围：1–3 |
| **潜行** | 敌方无法观察到本单位，直到"被发现" | |
| **被发现** | 本"潜行"单位处于敌方步兵攻击范围内，可被敌方观察 | 前线无敌方单位时，友方单位具有"潜行" |
| **防空** | 本单位与空军交战时，可反击，且视为与射程范围内步兵交战 | |
| **补给** | 友方回合开始时，本单位指向一个已受伤单位，将其修复 | |
| **冲锋** | 本单位首次攻击时，不受到反击伤害 | |
| **收缴** | 本单位消灭单位时，改为获得其 50% 生产所耗经济 G | 默认是 25% |
| **爆破** | 本单位攻击时，同时对敌方单位所在阵线工事造成等同于爆破等级伤害 | 爆破等级范围：1–2 |
| **修复** | 具有修复效果时可恢复 x 点防御力 | |
| **策反** | 本单位消灭敌方单位时，改为将一张复制加入手牌，视为金卡 | ⚠️ 暂缓（"先别端上来"） |
| **掩护** | 敌方炮兵或轰炸机无法攻击本单位 | ⚠️ 暂缓（"炮兵炸鸡超模再端"） |
| **巡逻** | 战斗机可以执行巡逻任务自动进攻本战线的空军。执行后敌方空军可以主动攻击友方空军；如果不执行，友方空军不会被锁定。巡逻需要在上回合结尾确认巡逻飞机 | 详见 3A 空战 |
| **钳击** | 钳击单位入场时，选择一个友方单位成为钳击伙伴，双方同时具有钳击加成。其中一方离场时钳击伙伴失去钳击加成 | |
| **工程** | 己方该阵线上存在"工程"单位时，该阵线工事的防御力上限由 2 提高至 6 | |

### 2.2 巡逻补充说明

若在敌方战斗机进攻后仍有友方同一阵线的战斗机没有被进攻，自动进攻敌方剩余战斗机且不受反击伤害。完整规则见 **3A 空战与巡逻**。

## 3. 交战规则

1. 单位仅能攻击或反击本单位射程范围内的格子
2. 单位攻击其他单位时，双方各自受到对方攻击力的伤害，即攻击与反击
3. 陆军无法攻击或反击空军
4. 轰炸机仅能攻击陆军
5. 非战斗机单位无法反击轰炸机
6. 单位无法反击火炮
7. 陆军单位无法反击空军
8. 轰炸机无法反击
9. 坦克默认具有**坚守 1**，坚守上限提升至 4
10. 工事效果：工事为同阵线的友方**陆军**单位提供**坚守**加成，数值 = 工事当前防御力 ÷ 2（向下取整），最高**坚守 2**；基础防御力上限 2，见 5.4 工事
11. 结算顺序：有敌方巡逻时战斗机进攻 → 随后陆军和轰炸机进攻。若没有敌方巡逻，即本回合没有空战，空军和陆军统一结算（流程化定义见 3A）
12. 工事可以被任何陆军开始建造，详见 5.4 工事

## 3A. 空战与巡逻（2026-09-20 增补）

### 3A.1 巡逻状态

1. **战斗机**（且仅战斗机）可以处于**巡逻**状态
2. **回合结束自动确认**：任一方的回合结束时，该方所有**本回合未进行过攻击**的战斗机自动进入巡逻状态；本回合攻击过的战斗机不进入巡逻（已在战斗中值勤）
3. 巡逻状态持续到该战斗机下次攻击、被消灭或下一次回合结束重算
4. 巡逻中的战斗机在自己回合仍是普通单位：可以被攻击、可以正常行动；巡逻**不是无敌拦截区**
5. 状态显示：巡逻中的战斗机在 UI 上有明确标识

### 3A.2 空战触发条件

当**空军单位发起攻击**（无论目标是对方空军还是陆军）时：

- 若目标所在阵线存在**防守方（被攻击方）处于巡逻状态的战斗机** → 触发该阵线的**空战阶段**
- 若目标阵线**没有**防守方巡逻战斗机 → **不发生空战**，直接按普通攻击结算（空军与陆军统一结算）

核心判断只有一条：**该阵线是否存在敌方巡逻战斗机？** 多个阵线**各自独立判断**，一条战线发生空战不影响其他战线。

### 3A.3 空战阶段结算流程（单阵线一次）

参与方定义：

- **进攻方参战单位**：发起本次攻击的空军单位 + 与其同阵线（空军图层）的其他**战斗机**（这些是"未被进攻"的友军）
- **防守方参战单位**：该阵线全部处于巡逻状态的战斗机

结算顺序：

```
① 巡逻拦截：防守方巡逻机逐一攻击进攻方参战单位
   （第一架攻击主动进攻者，其余攻击进攻方其余参战战斗机；拦截按正常攻防，可被反击）
② 未被进攻的自动反击：进攻方阵中未被拦截攻击过的战斗机，
   自动攻击防守方剩余巡逻机，且【不受反击伤害】
③ 每次伤害结算后立即移除阵亡单位，阵亡单位不再参与后续任何结算
④ 空战结束：双方参战存活名单即为空战结果
```

约束：

- 每个单位在一次空战阶段内最多攻击一次（拦截或自动反击二选一，不重复）
- 空战阶段不递归触发新的空战（拦截攻击本身不再触发巡逻判定）
- 原定攻击的后续见 3A.4

### 3A.4 空战后的对地攻击资格

空战阶段结束后：

1. 若**进攻方有参与本次空战且存活的战斗机**，且防守方巡逻机已被清空 → 进攻方（主动攻击者）**继续执行原定攻击**（对空或对地）
2. 若防守方仍有巡逻机存活 → 主动攻击者的本次攻击**作废**（行动已消耗），不再结算
3. **对地攻击资格严格绑定空战结果**：
   - 战斗机全部在空战中被击毁时，同阵线的轰炸机/其他空军**不得**仅因"存在于该阵线"而获得对地攻击资格——它们发起对地攻击时仍会触发巡逻拦截并被正常结算
   - 未参与本次空战的战斗机不能凭空满足"参与并存活"
4. 同一回合金币内：已参与空战的单位按 3A.3 的"每单位最多攻击一次"与原攻击的结算为准，不得通过巡逻/自动反击/普通攻击重复获得同一阶段的攻击机会

### 3A.5 无敌方巡逻时的结算

目标阵线没有防守方巡逻战斗机时：**本回合该阵线不存在空战**，不得人为制造空战阶段。空军攻击与陆军攻击按现有交战规则（第 3 节）**统一即时结算**：

```
有敌方巡逻：空战阶段 → 空战结算 → 存活战斗机确认 → 空军对地攻击 → 陆军攻击
无敌方巡逻：无空战 → 空军与陆军统一即时结算
```

### 3A.6 边界情况约定

- 多架巡逻机：一个阵线一次空战阶段包含该阵线全部巡逻机，不重复触发、不重复结算
- 一架飞机不因巡逻/自动反击/普通攻击在同一结算阶段获得多次攻击
- 阵亡单位（含刚被拦截击坠的）不参与任何后续结算
- 空军刚部署、刚移动后同样遵守本节规则（部署当回合可攻击，见 1.3）
- 战斗结束（phase=game_over）后不再触发任何结算

## 4. 显示与迷雾系统

### 4.1 迷雾系统

1. 敌方单位不可观察，一切信息（包括单位类型、数值、位置）初始具有"迷雾"
2. 敌方单位进入我方单位视野范围后，失去"迷雾"
3. 敌方单位离开我方单位视野时，重新获得"迷雾"，但保留"残影"便于记忆，直到再次失去"迷雾"

### 4.2 格子级迷雾可视化（2026-09-19 增补）

迷雾以**格子**为单位渲染，让玩家明确知道视野边界：

1. 所有**不在视野内**的格子（无论有无单位）一律显示迷雾覆盖效果；覆盖后格内单位与地形均不可见
2. **视野内**的格子正常透明显示，格上单位清晰可见
3. 我方单位所在格子**始终视为可见**（即使兵种视野范围不覆盖自身脚下）
4. 迷雾外的敌方单位因此不可探知——玩家只能知道"哪些格子我看得见"，不能知道"迷雾里有没有敌人"
5. 视野按当前视角玩家（本地同屏 = 当前行动方；联网 = 本地玩家）的己方单位实时计算

### 4.3 部署状态与单位状态显示（2026-09-20 增补）

1. **部署就绪标识**：部署阶段中，手牌的每张单位卡必须明确标识本回合**能否部署**（可以部署 / 不可部署），不可部署时给出原因（战争点 Z 不足 / 本回合购买且无"响应" / 无可部署位置）。标识必须来自引擎的真实规则判定，不允许 UI 自行猜测。
2. **单位状态标识**：棋盘上的单位必须显示其生效中的特殊状态，统一从单位状态数据（词条与等级）读取，至少包括：坚守（含等级）、巡逻中、守护中、防空、补给、潜行、突击、冲锋、收缴、已行动。表现方式为状态标签，具体样式随 UI 风格，但必须一眼可辨。

## 5. 战线占领度（2026-09-19 新增）

### 5.1 基本定义

- 棋盘的每一**行**为一条战线（默认 5×5 棋盘即 5 条战线）
- 每条战线有一个**占领度**数值，取值范围 **-100 ～ +100**
- 正值表示玩家 1（P1）占优，负值表示玩家 2（P2）占优；初始为 0
- 占领度是**公开信息**，双方均可在界面上看到每条战线的当前数值

### 5.2 占领度结算

**结算时机**：每个**完整回合**结束时更新一次。完整回合 = 双方各进行一个轮次（即 P2 行动结束、轮次回到 P1 时）。

**每条战线独立结算**，规则如下：

| 战线上的单位情况 | 占领度变化 |
|------------------|-----------|
| 同时存在双方阵营单位 | **不变** |
| 无任何贡献单位 | **不变**（已占领的战线保持占领状态） |
| 仅有一方阵营单位 | 向该方推进，数值 = 该方所有贡献单位权重之和 |

**贡献单位与权重**（仅以下三种陆军参与占领，其余兵种不贡献）：

| 单位 | 权重 |
|------|------|
| 骑兵 | 25 |
| 步兵 | 50 |
| 坦克 | 100 |

- 多个单位叠加计算（如 2 个步兵 = +100），结算后封顶到 ±100
- 例：战线为 +100（P1 已占领），P2 派 1 个步兵进入且 P1 无单位 → 每回合 -50，4 个回合后变为 -100，被 P2 夺取

### 5.4 工事（2026-09-20 定稿）

1. **修筑者与条件**：行动阶段中，己方任意**陆军**单位（不含空军与工事自身）可在**友方占领度达到 100%** 的阵线修筑工事；每条阵线最多存在 **1 个**工事
2. **修筑消耗与放置**：修筑消耗该单位本回合**全部行动** + 战争点 **2**；工事放置于该阵线（同地面图层占位规则）的一个空格
3. **防御力**：基础防御力为 **2**（即防御力上限，规则 12）；若同阵线存在己方**工程**单位，上限提升至 **6**（规则 10 + 工程词条的调和：上限 2 → 有工程时 6）。修筑时直接以当前上限值入场
4. **坚守加成**：工事为**同阵线**的友方陆军单位提供坚守，数值 = 工事当前防御力 ÷ 2（向下取整），最高坚守 2（详见交战规则第 10 条）
5. **可破坏与重建**：工事可被攻击（无攻击力、无法移动、无法反击）；防御力归零即被摧毁；被摧毁后该阵线可再次修筑
6. **占领度**：工事不贡献占领度（占领权重仅骑兵/步兵/坦克）
7. 工事不是卡牌，不进入卡组，仅通过修筑产生

### 5.3 胜利条件（取代旧版"渗透胜利"）

- **P1 胜利**：5 条战线占领度全部达到 **+100**
- **P2 胜利**：5 条战线占领度全部达到 **-100**
- 胜利判定仅在占领度结算后进行（完整回合结束时）
- 旧版规则（"在敌方区域每列都有单位"）**废止**，由本机制取代

## 6. 卡牌与资源系统

### 6.1 三种资源

| 资源 | 用途 | 获取方式 | 累积规则 |
|------|------|----------|----------|
| **经济 G** | 生产单位 | 每回合开始获得 150 | 可无限累积 |
| **战争点 Z** | 部署单位、移动/攻击 | 每回合开始获得对应回合数的 Z | 每回合结束时清空 |
| **指挥点 K** | 使用指令卡（阶段5+） | 每回合开始获得对应回合数的 K | 每回合结束时清空 |
| **油费（卡牌属性）** | 每张卡牌的固定数据属性 | 非回合资源：不随回合产生或清空 | 使用/部署该卡牌时一次性检查并消耗 |

### 6.2 卡牌流转

- 先手第一回合不抽牌，之后每回合开始抽一张牌
- 每回合抽牌时，单位卡 → 加入待购买区；指令卡 → 加入指令区
- **每回合购买数量上限（2026-09-20 修订，按稀有度）：** 铜卡（common）不限，银卡（silver）每回合最多购买 **3** 张，金卡（gold）每回合最多购买 **2** 张。上限与抽取数量无关——抽取多少不改变可购买数量
- 单位购买后加入手牌，**手牌上限为 7**
- 初始从卡组中抽出 3 张卡牌
- 双方构造卡组时，将一张单位设为首发牌，恒定加入第一回合购买区

### 6.3 单位生命周期

```
抽到单位卡 → 进入待购买区 → 花费经济G购买 → 进入手牌
→ 次回合（或有"响应"时当回合）花费战争点Z部署 → 进入战场（后方/前线）
→ 部署当回合：可按攻击规则攻击（空军见 3A）；不能移动（"突击"单位例外，可移动+攻击）
→ 次回合起：正常行动（移动/攻击，消耗战争点Z）
```

### 6.4 特殊规则

- 单位处于后方时具有**修复 1**

## 8. 阵营机制

### 8.1 沙俄 → 苏俄 转换

- 沙俄阵营在对局开始后**经过一定时间（回合数）**，触发转型
- 转型时，**待购买区中的所有沙俄单位替换为对应的苏俄单位**
- 已部署在场上的单位、手牌中的单位不受影响
- 转型后，后续抽到的单位均为苏俄单位

> 具体转型回合数、单位对应关系待定。
