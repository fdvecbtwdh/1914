# 1914 AI 对战系统设计（2026-09-20）

## 1. 模式与接入

- 主菜单新增「人机对战」：三档难度（简单 / 普通 / 困难），玩家固定为 P1（player 0），AI 执 P2（player 1）
- AI 走与玩家完全相同的指令通道：`TurnManager.submit_action()` → `GameLogic` 纯函数校验链。**AI 没有任何绕过规则的代码路径**——非法行动在引擎层返回 null，与玩家一致
- AI 与本地同屏模式共用战斗场景；`GameManager.ai_player_idx >= 0` 表示 AI 对战中

## 2. 架构（scripts/ai/）

| 文件 | 职责 |
|------|------|
| `ai_config.gd` | 三档难度参数（评分噪声、候选池、风险意识、侵略性），纯数据 |
| `ai_evaluator.gd` | 局面分析 + 合法行动枚举 + 评分（纯函数，无节点依赖） |
| `ai_controller.gd`（AIDirector） | 回合驱动状态机：行动 → 状态变化 → 重新评估 → 下一行动 |

行动枚举采用**预演验证**：对每个候选行动直接调用 `GameLogic.purchase_card / deploy_unit / move_unit / attack_unit / build_fort` 试算，返回非 null 才进入候选池。因此：

- AI 提交的行动必然被引擎接受（同状态同参数确定性结果），不存在「被拒 → 重试 → 死循环」
- 引擎新增任何行动类型 / 卡牌 / 词条时，AI 的合法性判断自动跟随规则变化，无需修改 AI 核心评分器（新行动类型需在枚举与评分函数中补一项，其余自动兼容）

## 3. 信息范围（不作弊）

- AI 只读取**战场明面信息**：双方在场单位、战线占领度、资源、自己手牌与购买区
- **不读取**玩家手牌、购买区内容
- 攻击目标枚举受**战争迷雾约束**：AI 只能攻击 `compute_visible_cells(state, ai_idx)` 视野内的敌方单位（与处于同位置的玩家可见信息一致）
- 没有任何难度通过无限资源 / 无视费用 / 直改战斗结果提升强度

## 4. 难度（ai_config.gd）

| 参数 | 简单 | 普通 | 困难 |
|------|------|------|------|
| 评分噪声 noise | ±40 | ±12 | ±3 |
| 候选池 pool（按分随机取前 N） | 3 | 2 | 1 |
| 风险意识 risk_aware（评估反击/空战风险） | 否 | 是 | 是 |
| 威胁规避 threat_aware（远离强敌/保护高价值单位） | 否 | 弱 | 强 |
| 侵略性 aggression | 0.7 | 1.0 | 1.0 |
| 经济策略 | 见卡就买 | 买性价比最高 | 性价比 + 前线需求 |

- 简单：偏眼前收益、允许明显次优选择，但**不是随机行动**（仍从合法候选的 top 池选择）
- 普通（默认）：完整评分 + 小噪声
- 困难：近乎确定性选择，附加威胁规避、工事与阵线价值评估

## 5. 评分概要（可解释、可调试）

每个候选行动得分（越高越好），调试模式下可输出候选与评分：

- **攻击**：目标价值 ×（击杀 1.5 / 重创 0.6）− 预期反击损失（按反击规则判断是否被反击）− 空战风险（目标线有敌巡逻且我方无空中支援时大幅减分）
- **移动**：向前推进 + 占领无人战线 + （困难）脱离更强敌人威胁
- **部署**：单位战力 − 成本比重 + 部署到有敌情战线的加成
- **购买**：单位性价比（战力 / G），受稀有度上限自然约束
- **修筑工事**：战线已 100% 占领且存在敌情时中高分（困难 AI 更积极）
- **结束回合**：恒 0 分兜底——无更高分候选时自然结束回合

AI 每执行一个行动后**重新评估**（前序行动可能击杀目标、腾空格、改变战线状态），不预生成固定行动列表。

## 6. 回合驱动与体验

- AIDirector 在轮到 AI 时异步驱动：`思考间隔（默认 0.45s，可配）→ 选最佳行动 → submit → 等状态变化 → 循环`；无行动可做时提交 end_turn
- 防软锁三重保险：状态无进展看门狗（强制 end_turn）、单回合行动计数上限（200）、`game_over` 即停
- UI：AI 回合横幅显示「AI 行动中（难度）」；AI 行动节奏与人类可感知（间隔存在），不刷屏
- 视角：AI 对战中棋盘视角锁定玩家侧（`board._viewer_idx`），避免热座视角切到 AI 造成玩家眩晕

## 7. 随机性与复现

评分噪声使用全局 RNG；测试可通过 `seed(n)` 复现相同决策序列（同牌组 + 同种子 → 同对局）。

## 8. 已知限制

- 无跨回合战略规划（不记忆上一回合计划）；困难 AI 的「预测」体现为风险与威胁评估，而非对手建模
- 卡牌系统当前只有单位卡（指令卡未实装），AI 的卡牌评估随指令卡上线需扩展 CardEvaluator
- AI 不主动利用「巡逻」词条做布防规划（巡逻由引擎回合结束规则自动确认，AI 行为自然兼容）
