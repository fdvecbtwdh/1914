| 项 | 改动 |

### M2 Android 导出管线（提交 `84ac03b`、`9bf16a6`）

- 在本机搭建完整导出环境：JDK 17（清华镜像）+ Android SDK（腾讯镜像：build-tools 34 / platform 34 / platform-tools）+ Godot 4.7.2 导出模板（官方 CDN）
- **`build/1914.apk` 已产出（57MB，arm64-v8a，Android 7.0+，含 INTERNET 权限）**，包名 `com.fdvecbtwdh.g1914`
- 导出预设 `export_presets.cfg` 入库，以后一条命令重新出包：
  `godot --headless --path . --export-debug "Android" build/1914.apk`
- 环境依赖清单（JDK/SDK/模板位置）见本机 `build-env/`（不入库），搭建要点已记录在本报告附录

### M3 跨网联机客户端 + 服务器部署物料（提交 `f24c454`）

- 修复中继握手缺口：连上服务器后补发 `join`；`ready` 改为入房后发送（场景先就绪的情况会补发）
- 主菜单新增"跨网联机"区：中继服务器地址 + 房间码（自动生成 4 位）+ 创建/加入按钮
- `deploy/relay-server.js`：轻量中继服务器（Node.js ~50 行，按房间码透传字节，1核512MB 可扛数千房间），`npm install ws && node relay-server.js` 即可运行
- 协议文档与实现同步（`docs/server-relay-protocol.md`）

## 二、还差两步（需要人参与）

1. **真机验证（需要你）**：把 `build/1914.apk` 传到 Android 手机安装（允许未知来源），验证：本地对战 → 与 PC 局域网对战（同一 WiFi，主机开"创建局域网游戏"，手机"搜索局域网主机"或手输电脑 IP）→ 触屏操作全流程
2. **中继服务器部署（需要服务器权限）**：把 `deploy/` 传到你们服务器 `npm install && node relay-server.js`（或 pm2 守护），然后把游戏主菜单"中继服务器地址"从默认值改成 `ws://你的服务器IP:24566`。部署后手机在任何网络（含流量）都能通过房间码与电脑对战
